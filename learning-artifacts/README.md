# Learning Artifacts

Personal work for the course. The upstream course does not track this folder, so your notes and experiments merge cleanly when you pull updates.

```text
learning-artifacts/
  phase-01/
    lesson-01/
      notes.md
      vectors.py
  experiments/
```

## Rules

- Never edit a reference lesson file to make an exercise pass.
- Copy lesson code here before changing it.
- Put a short `notes.md` next to each artifact: goal, command, evidence, what is still fuzzy.
- Keep artifacts small and reproducible. Do not commit datasets, model weights, or `.venv`.
- Mark finished lessons in `../PROGRESS.md`.
